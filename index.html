怎么用

  1. 加图片：点上传框、把文件拖进来，或者从 PS 复制后直接 Ctrl+V 粘贴。可以一次加几十张。
  2. 填尺寸：每张图输入成品宽 × 高（cm）。小锁头亮着时保持原图比例，改宽自动算高；点一下锁头可以单独改宽高。
  3. 填数量：要印几个就填几个，工具自动复制这么多份。
  4. 调间距：「图片间距」是留给你下剪刀的缝，默认 4mm。想更宽敞就调到 5–8mm。
  5. 导出：点右上角「导出大图」，得到透明底 PNG（300dpi）。多页会自动打包成一个 zip。
两种排版方式
· 顺序不变 · 从左到右：严格按左边素材列表的顺序排，一行排满才换下一行，小图不会回头填空位，位置最好预期。
· 按尺寸分组 · 补空隙：先把尺寸相近的图归到一起（同款大图会排成整排，方便找），再从最上面的空隙开始往下填——行尾的空档、矮图下方的空白都会用上，最省纸。
素材顺序直接拖动缩略图就能调。
网页上存不下来的图（Temu / 微信 / 小红书的定制图案）
这类图右键存不了，但浏览器复制时会把画面放进剪贴板，所以照样能弄进来：
1. 先在网页上按 Ctrl+加号 把图案放大（截出来的像素更多，印着更清楚）；
2. 按 Win+Shift+S 框选这块图案；
3. 回到这里按 Ctrl+V，它就会作为一张图加进素材。
也可以在网页上右键「复制图片」后直接粘贴。加进来如果显示的有效 dpi 偏低，把它的成品尺寸改小一点就行。
关于能不能印清楚：每张图右侧显示「有效分辨率」。绿色 ≥240dpi 很清晰，橙色 150–240dpi 可以接受，红色低于 150dpi 印出来会发虚——这时要么把成品尺寸改小，要么换更清晰的源图。
关于尺寸：导出的 PNG 里已经写入 300dpi 的物理分辨率信息，PS / AI / 打印软件打开时就应当是你在左边设置的厘米数。如果 PS 显示的尺寸不对，多半是打开时按 72dpi 解释了——在 PS 里「图像 → 图像大小」，取消勾选「重新采样」，把分辨率改成 300，宽度就会自动回到正确值。

打印小贴士：导出的 PNG 是 RGB 色彩。印刷厂要 CMYK 的话，把 PNG 拖进 PS → 图像 → 模式 → CMYK 颜色。打印时务必选「实际大小 / 100%」，不要勾「适合纸张」。
